# たっぴぃず録音（lecture-notes）

講演を録音しながら文字起こしし、AI で整えて記録する、自分専用の Android アプリ。

## 入れ方・更新

1. [Releases](https://github.com/tapeinooo/lecture-notes/releases/latest) から `lecture-notes-v1.0.N.apk` をスマホでダウンロードして開く（「この提供元のアプリを許可」をオンにする）。
2. 2回目からは、アプリが起動時に新しい版を見つけて「更新する」ボタンを出す。

`main` に書き込むと GitHub Actions が APK を作り、Releases に `v1.0.<実行番号>` として出す。

## 使い方

1. 設定で Groq と Gemini の API キーを入れる（どちらも無料）。「つながるか確かめる」で使えるモデルの名前が出る。
2. 「● 新しく録音する」ですぐ録音が始まる。上の欄でタイトル・話し手（一度入れた名前は候補に出る）・ラベル（集会・講演・大会・その他。足せる）を入れる。画面を消しても録音は続く（通知に「録音中」が出る）。
3. 気になったところで「★ 印を付ける」（メモも付けられる）。文章を長押しするとマーカー、タップするとその場で直せる（別の窓は開かない。文字を選んでマーカーも引ける）。★はすぐ付き、メモは画面の下の帯で書ける。
4. 休憩では「停止」、再開は「続きを録音する」。
5. 一覧はラベルで絞り込め、🗑 で削除できる。終わったら「…」→「文章を書き出す」（Markdown。Google ドライブなどに送れる）。音声も書き出せる。

## しくみ

- その場の表示：端末内の音声認識（Android 13 以上）で、話した直後に文字を出す。区切りごとにクラウドの文字起こし（清書）で置き換え、さらに AI で整形・仕上げする。
- 録音：16kHz・モノラルの AAC（m4a・32kbps）を、10秒を過ぎた文の切れ目（0.6秒の間）か、目安（既定 15 秒）を過ぎた静かなところで区切って保存する（Groq は1回10秒分として数えるので、それより短くしない）。1時間でおよそ 14MB。文字起こしの方法とは関係なく、音声は必ず残る。前の版の WAV は、文字起こしが済んだら裏で m4a に変える。
- 文字起こしの方法（設定で切り替え）
  - **自動**：Groq（Whisper）→ Gemini → 端末内 の順に、使えるものを選ぶ。制限にかかったサービスはしばらく休ませ、次に回す。オフラインの間は端末内で起こし、ネットが戻ったらクラウドで起こし直す。
  - **Groq** / **Gemini** / **端末内**：それだけを使う。
- モデルの使い分け（設定の「自動で選ぶ」）：使えるモデルの一覧を半日ごとに取り直し、役割ごとに順番を付ける。
  - 聞き取り：Groq の Whisper（large-v3 → turbo。それぞれ別の枠）→ Gemini の Flash 系（新しい版から）→ Flash-Lite → Pro。
  - 整形：Gemini の Pro → Flash → Flash-Lite → Groq の大きなモデル（Kimi K2・gpt-oss など）→ Gemma（1日の回数が多い）。
  - すぐの整形は Flash-Lite → Groq → Flash の順（新しい Flash は遅いことがあるため、仕上げに回す）。考える時間は minimal（受け付けないモデルは low）に。
  - 実際にかかった時間を役割ごとに測り、遅いモデル（聞き取り12秒・すぐの整形10秒・仕上げ90秒を超える）は自動で後回し。打ち切り（40・25・150秒）になったら、その役割で15分休ませる。6時間たったら測り直す。
  - 上から使い、制限にかかったモデルは休ませて次へ。1日の上限なら太平洋時間の0時まで、無料枠で使えないモデルは24時間休ませる。整形の結果の形が崩れたら次のモデルで試す。
  - 設定の画面に、役割ごとの順番・休み中かどうか・今日使った回数が出る。自動をやめると順番を自分で書ける。
- 整形は2段階。すぐの整形：話に長めの間（約2秒）があり、たまった音声が15秒以上ならまとめて（間がなくても45秒で）、考える時間を切った速いモデル（Flash-Lite・Flash・Groq）で直す。仕上げ：8区間ずつ、頭の良いモデル（Pro・新しい Flash）で裏で直し直す（遅いモデルでも新しい文字の表示を待たせない）。どちらも句読点・誤認識・用語を直す。用語集（設定から編集。wol.jw.org の「用語集」を貼り付けて見出し語を取り込める）と、新世界訳・wol.jw.org の表記に合わせるよう指示している。
- 聖句：「ヨハネ 3:16」「マタイ24章14節」のような参照を見つけて、wol.jw.org の該当の章へのリンクにする。本文は取りに行かない（jw.org の利用規約で、サイトから自動でデータを取り出すことは禁じられているため）。

- トークンの節約：整形の指示の決まった部分（規則・用語集）を毎回同じ先頭に置き、Gemini の自動キャッシュが効くようにしている。記録ごとに変わる直し・マーカーは後ろに。すぐの整形は用語集を短くして送る。
- 画面：録音の操作（開始・★・停止）は上。停止は2回押して止める。歯車からいつでも設定へ（録音中に変えても次の区切りから効く）。時刻は1分ごとに小さく打刻。

## 無料枠の目安と注意

- Groq の Whisper は、1日に文字起こしできる音声の長さに上限がある（目安 8 時間）。超えたら自動で Gemini に回り、それも尽きたら端末内か送信待ちになる。送信待ちの分は、翌日に制限が戻れば続きから処理される。
- 無料枠では、送った音声や文章がサービスの改善に使われることがある。
- 音声は 1 時間でおよそ 14MB。

## 署名の鍵について

更新でインストールし直すには毎回同じ鍵で署名する必要があるため、鍵（`app/release.keystore`）をリポジトリに置いている。アプリは自分のリポジトリの Releases からしか更新しないので、自分用としては問題ないが、他の人にも配るなら鍵を GitHub の Secrets に移すこと。
